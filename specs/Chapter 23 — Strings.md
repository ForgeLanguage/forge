# Глава 23 — Строки

`String` — встроенный неизменяемый тип. Строковые операции являются методами
экземпляра и доступны без `use`:

```forge
const source = "  Forge  "
const name = source.trim()
const size = name.length()
const found = name.contains("org")
```

Старый статический API `std.Text.Text` удалён. Это намеренная несовместимая
миграция:

```forge
// Было
Text.substring(value, 1, Text.length(value))

// Стало
value.substring(1, value.length())
```

## Байтовая модель

Текущий runtime хранит `String` как строку `char*`, завершённую нулевым байтом.
Поэтому:

- `length()` возвращает количество байтов до первого `NUL`, а не число Unicode
  code points;
- индексы и диапазоны задаются в байтах;
- `toLowerCase()`, `toUpperCase()` и `trim()` имеют ASCII-семантику;
- байты `>= 128` при смене регистра не изменяются.

`trim()` удаляет только ASCII-пробел `0x20` и управляющие whitespace-байты
`0x09`–`0x0D`.

## Методы экземпляра

```forge
text.length(): Int
text.isEmpty(): Bool
text.toBytes(): Byte[]
text.equals(other: String): Bool
text.indexOf(needle: String): Int
text.contains(needle: String): Bool
text.startsWith(prefix: String): Bool
text.endsWith(suffix: String): Bool
text.substring(start: Int, end: Int): String
text.trim(): String
text.toLowerCase(): String
text.toUpperCase(): String
text.replace(old: String, replacement: String): String
text.split(separator: String, limit: Int): String[]
text.parseInt(): Int
```

`equals()` сравнивает содержимое строк побайтно. Оператор `==` для `String`
пока не является пользовательским строковым сравнением.

`indexOf()` возвращает байтовый индекс первого совпадения или `-1`. Пустая
искомая строка находится в позиции `0`; `contains("")`, `startsWith("")` и
`endsWith("")` возвращают `true`.

`replace()` заменяет все непересекающиеся совпадения. Пустой `old` не вставляет
текст между байтами, а возвращает копию исходной строки.

`split()` сохраняет пустые элементы при начальном, конечном и повторяющемся
разделителе. Второй параметр `limit` повторяет семантику одноимённого параметра
PHP `explode()`:

- при `limit > 0` массив содержит не более `limit` элементов, а последний
  элемент включает неразделённый остаток;
- `limit == 0` трактуется как `1`;
- при `limit < 0` из полного результата исключаются последние `-limit`
  элементов; если исключены все элементы, возвращается пустой массив.

```forge
const limited = "a,b,c,d".split(",", 2) // ["a", "b,c,d"]
const withoutLast = "a,b,c,d".split(",", -1) // ["a", "b", "c"]
const parts = "a,,b,".split(",", 2147483647) // ["a", "", "b", ""]
```

Пустой разделитель сохраняет прежнее поведение Forge: до применения
отрицательного `limit` полным результатом считается массив из одной копии
исходной строки. Поэтому положительный `limit` возвращает эту одну часть, а
отрицательный — пустой массив.

## Диапазоны и отрицательные индексы

`substring(start, end)` использует полуоткрытый диапазон `[start, end)`.
Отрицательный индекс отсчитывается от конца строки:

```forge
"abcdef".substring(-4, -1) // "cde"
"abcdef".substring(4, -1)  // "e"
```

Каждый индекс нормализуется независимо:

1. если `i < 0`, вычисляется `length + i`;
2. результат ограничивается диапазоном `[0, length]`;
3. если нормализованный `end < start`, возвращается пустая строка.

Поэтому слишком отрицательный индекс становится `0`, а слишком большой —
`length`.

## Преобразования

Операции без строкового receiver остаются статическими фабриками:

```forge
String.fromBytes(bytes: Byte[]): String
String.fromInt(value: Int): String
```

`String.fromBytes()` останавливается на первом `NUL`, поскольку текущая
`char*`-модель не может представить встроенный нулевой байт.

`parseInt()`:

- пропускает начальные ASCII whitespace-байты, определённые для `trim()`;
- принимает один необязательный знак `+` или `-`;
- читает десятичные цифры до первого другого байта;
- возвращает `0`, если цифр нет;
- ограничивает переполнение значениями `Int.MIN` и `Int.MAX`.

## Владение

Методы, возвращающие `String`, `Byte[]` или `String[]`, создают владеющий
результат. Присваивание локальной переменной или `return` передаёт владение.
Временные вложенные и отброшенные массивы освобождаются после полного
выражения; для `String[]` освобождаются и элементы, и буфер массива.
