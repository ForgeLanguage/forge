До этого мы писали код внутри `main`.  
Теперь разберёмся, что такое класс и объект.

---

# 1. Класс

Класс — это описание структуры и поведения.

Он определяет:

- какие данные хранит объект
- какие операции с ним можно выполнять

Пример:

```forge
class

public name: String
```

Это класс с одним полем `name`.

Сам по себе класс — это только описание.  
Чтобы работать с данными, нужно создать объект.

---

# 2. Объект

Объект — это экземпляр класса.

Он создаётся через `new`.

```forge
class

public static main(args: String[]): Void {
    const g: Greeter = Greeter.new("Forge")
}
```

Здесь:

- `Greeter` — класс
- `g` — объект этого класса

Каждый объект имеет своё собственное состояние.

---

# 3. Экземплярные поля

```forge
class

public name: String
```

Каждый созданный объект имеет собственное поле `name`.

Если создать два объекта:

```forge
const a: Greeter = Greeter.new("Alice")
const b: Greeter = Greeter.new("Bob")
```

то:

- `a.name` и `b.name` — разные значения
- изменение одного не влияет на другой
## 3.1. Доступ к полям

Доступ к полям объекта осуществляется через оператор `.`

```
const g: Greeter = Greeter.new("Forge")  
  
print g.name
```
Здесь:

- `g` — объект
- `name` — его поле
- `g.name` — доступ к значению поля

## Изменение значения

```
g.name = "NewName"
```

Изменяется только этот объект.

## Групповой доступ к членам объекта

Если нужно выполнить несколько операций с одним объектом, можно сгруппировать обращения после `.`:

```forge
var.{
    field1 = 1
    field2 = "str"
    callSomeMethod()
    callAnotherMethod()
}
```

Это синтаксический сахар для последовательных обращений к тому же объекту:

```forge
var.field1 = 1
var.field2 = "str"
var.callSomeMethod()
var.callAnotherMethod()
```

Внутри блока:

- присваивание `field = value` разворачивается в `var.field = value`
- вызов `method()` разворачивается в `var.method()`

## Доступ внутри класса

```
public rename(newName: String): Void {
    this.name = newName  
}
```

`this` указывает на текущий объект.

## Доступ к static-полям

```
print Greeter.count
```

или:

```
self.count = self.count + 1
```

## Цепочка доступа

```
user.address.city
```

Каждый шаг берёт следующее поле.

# 3.2. Nullable значения и безопасный доступ

Тип может быть nullable:

```
public age: Int? = null
```

Это означает, что поле может содержать значение или `null`.

## Проблема обычного доступа

```
user.address.city
```

Если `address == null`, это приведёт к ошибке выполнения.

## Безопасный доступ (`?.`)

```
user?.address?.city
```

Поведение:

- если любой элемент цепочки равен `null`
- результат всего выражения — `null`
- выполнение не прерывается ошибкой
## Пример

```
const city: String? = user?.address?.city
```

## Комбинация с `??`

```
const city: String = user?.address?.city ?? "Unknown"
```

Если значение `null`, используется значение справа.
## Важные правила

- `?.` применяется только к nullable-значениям
- результат выражения тоже становится nullable
- обычный `.` используется, если значение гарантированно не `null`

---

## Сравнение

```
user.address.city   // требует, чтобы address != null  
user?.address?.city // безопасный вариант
```

## Проверка на `null`

Если значение может быть `null`, есть два способа безопасного доступа:

### 1. Явная проверка

```
if user.address != null {  
    print user.address.city  
}
```

В этом случае:

- после проверки доступ через `.` безопасен
- программист явно контролирует логику

### 2. Null-safe доступ

```
print user?.address?.city
```

- короче
- не требует дополнительных условий
- возвращает `null`, если значение отсутствует

## Правило

> Если значение может быть `null`, необходимо:
> 
> - либо проверить его перед доступом
> - либо использовать `?.`

## Неправильно

```
print user.address.city   // ❌ если address может быть null
```

## Когда что использовать

- `if` — когда нужна логика ветвления
- `?.` — когда нужно просто безопасно получить значение

# 💡 Итог

- `.` — обычный доступ
- `?.` — безопасный доступ
- `T?` — nullable тип
- `??` — значение по умолчанию

# 4. Static члены

`static` означает: член принадлежит **классу**, а не объекту.

Он общий для всех экземпляров.

---

## Static поле

```forge
class

public static count: Int = 0
```

Это поле существует в одном экземпляре для всего класса.

Все объекты видят одно и то же значение.

---

## Static функция

```forge
public static version(): String {
    return "1.0"
}
```

Вызывается так:

```forge
print App.version()
```

`static` функции:

- не используют `this`
- работают на уровне типа

---

# 5. Static и объекты

Пример:

```forge
class

public static count: Int = 0
public name: String

public new(name: String) {
    this.name = name
    self.count = self.count + 1
}
```

Конструктор может объявлять поля прямо в списке параметров:

```forge
class Point

public new(
    public x: Int,
    public y: Int
) {
    print x
}
```

Это эквивалентно:

```forge
class Point

public x: Int
public y: Int

public new(x: Int, y: Int) {
    this.x = x
    this.y = y
    print x
}
```

Инициализация promoted fields всегда выполняется до тела конструктора.

Каждый раз при создании объекта:

- поле `name` хранится в объекте
- `count` увеличивается в классе

Если создать три объекта:

```forge
Greeter.new("A")
Greeter.new("B")
Greeter.new("C")
```

`Greeter.count` будет равно `3`.

---

# 6. `this` и `self`

|Ключевое слово|Значение|
|---|---|
|`this`|текущий объект|
|`self`|текущий класс|

- `this.name` — поле объекта
- `self.count` — статическое поле класса

`self` также можно использовать как тип текущего класса внутри объявления класса:

```forge
class Point

public new(public x: Int, public y: Int) {}

public static origin(): self {
    return self.new(0, 0)
}

public same(other: self): self {
    return other
}
```

Вне класса тип `self` недоступен.
