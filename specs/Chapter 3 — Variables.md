# The Forge Book



В Forge переменные объявляются явно.

Есть два вида переменных:

- `const` — неизменяемые
- `var` — изменяемые

Для локальных переменных слово `const` или `var` обязательно.
Для полей типа слово можно опустить; тогда действует дефолт контейнера:
поля `class` по умолчанию `const`, поля `struct` по умолчанию `var`.

Тип можно указать явно или вывести из инициализатора.

---

## `const`

```forge
class

public static main(args: String[]): Void
{
    const message: String = "Hello"
    print message
}
```

`const` означает:

- значение задаётся один раз
- повторное присваивание запрещено

Это значение, которое не меняется.

---

## `var`

```forge
class

public static main(args: String[]): Void
{
    var counter: Int = 0
    counter = counter + 1

    print counter
}
```

`var` позволяет изменить значение после объявления.

---

## Тип переменной может быть выведен

```forge
const n = 10
var name = "Forge"
```

---

## Деструктуризация массивов

Локальное объявление может связать несколько имён с первыми элементами массива.
Если размер массива статически известен и элементов достаточно, дополнительная
обработка не нужна:

```forge
const values: Int[3] = [10, 20, 30]
const [first, second] = values

print first  // 10
print second // 20
```

Та же форма доступна для изменяемых переменных:

```forge
var [left, right] = values
left = left + 1
```

Для массива неизвестной или динамической длины обязателен `catch` с
`PatternMismatch`:

```forge
const parts = requestLine.split(" ", 3)
const [method, path, protocol] = catch parts {
    issue: PatternMismatch => {
        return HttpIssue.new("Invalid request line")
    }
}
```

Перед чтением элементов runtime сравнивает `parts.len` с количеством имён.
Короткий массив выполняет handler `PatternMismatch`, не обращаясь за границы.
Если длины достаточно, первое имя получает элемент `0`, второе — элемент `1`
и так далее.

Непосредственный литерал также имеет статически известную длину:

```forge
const [red, green, blue] = [255, 128, 0]
```

Статически известный слишком короткий массив является ошибкой компиляции.
Проверка `if values.len >= 3` пока не делает динамический тип статическим:
для такого массива `catch` всё равно обязателен.

Правая часть должна иметь тип массива и вычисляется ровно один раз. Тип каждого
имени выводится из типа элемента массива. Первая версия деструктуризации не
поддерживает пропуски, rest-элементы, вложенные шаблоны и присваивание в ранее
объявленные переменные.


---

Вот и всё.

- `const` — значение
- `var` — переменная
- тип указывается через `:`
- тип может быть выведен из инициализатора
- `[a, b]` в локальном объявлении связывает первые элементы массива
- присваивание — через `=`
